# SEAR

**Structured Evidence-Guided Affective Reasoning for Training-Free Multimodal Emotion Recognition**

## English

SEAR is a training-free framework for multimodal emotion recognition through structured evidence construction and evidence-guided affective reasoning.

### Code availability

The code and implementation details will be made publicly available in this repository. Thank you for your interest and patience!

## 中文

SEAR是一种通过结构化证据构建与证据引导的情感推理，实现多模态情绪识别的免训练框架。
